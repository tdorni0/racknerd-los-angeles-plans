## 线路实测：联通舒服，电信将就，移动别买

关于这台机器的国内网络，早期测评和 2026 年初的晚高峰长测结论并不一致，这个分歧值得说清楚。

早期说法是三网都还行，联通移动丢包少，电信晚高峰轻微抖动。2026 年 1 月有博主在晚高峰 21:00–23:00 连续测了几个小时，结论要尖锐得多：联通方向 IPv4 单线程跑到 **318Mbps**，没有明显限速；电信能撑住 YouTube 4K，但大文件下载不理想；移动基本不能用。

两份数据我更信后者，它有具体时间、具体协议、具体速率曲线。所以按运营商给结论：

- **联通宽带**：这台机器的主要受益者，晚高峰速度掉得不多。
- **电信宽带**：看视频、查资料可以，天天下载大文件会难受。
- **移动宽带**：不建议，省下的钱不够补偿你花在等待上的时间。

对延迟极其敏感的场景（实时游戏、远程桌面），197ms 这个量级本身就不合适，普通 BGP 线路没有 CN2 GIA 那种优化，需要自己叠加加速工具。RackNerd 全线没有 CN2 GIA 产品，这是它的定位决定的，不是配置没选对。
